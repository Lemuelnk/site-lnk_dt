# PASS 3.5 — Final pre-audit adjustments

Two changes only, with the existing design otherwise preserved:

1. **Hero CTA** — removed only the `↗` arrow from `Parlons de votre projet`.
2. **Portfolio viewer** — added an overlay lightbox for portfolio cards:
   - opens the selected project/sample in large view;
   - zoom controls: `−`, percentage/reset, `+`;
   - mouse-wheel zoom on desktop;
   - left/right navigation between media in the selected category;
   - swipe left/right on touch devices;
   - previous/next and Escape keyboard controls;
   - close button and backdrop close;
   - no change to the existing portfolio layout, filters, typography, colors or card structure.

The existing Pass 3 locked sections were not intentionally redesigned.
