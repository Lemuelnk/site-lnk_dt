# CONTACT POLISH — v1

Applied to the latest LNK Design Touch site package.

- Contact email display and mailto target normalized to lowercase.
- WhatsApp icon in the dark direct-contact panel now uses the LNK teal for stronger contrast.
- Replaced the browser-native `Choose File` presentation with a branded, keyboard-accessible attachment button.
- After file selection, the UI shows the selected filename and size and changes the action label to `Modifier la pièce jointe`.
- After a successful form reset, the attachment UI returns to its initial state.
- Existing 10 MB client-side attachment limit and accepted file types remain unchanged.
- Existing layout, responsive behavior, form endpoint, and overall visual direction were preserved.
