# HERO — Section 01 refinement

## Scope
Only the Hero responsive composition was refined. The existing visual direction and content were preserved.

## Changes
- Desktop Hero vertical padding reduced so the headline, supporting copy and CTAs fit more reliably within common laptop/desktop viewport heights.
- Desktop Hero typography slightly recalibrated to prevent the headline from being clipped by short viewports.
- Desktop visual frame scale and vertical placement tightened without changing the artwork concept.
- Desktop CTA spacing tightened.
- Tablet spacing/typography received a dedicated intermediate rule set.
- Mobile Hero vertical rhythm tightened slightly while preserving the stacked composition and large visual.

## Intentionally unchanged
- Hero copy/content
- Color palette
- Grid treatment
- CTA labels
- Mockup artwork structure
- Other website sections
- Header/logo assets (to be handled in their own section/task)
